The Task

Sample Image #1 — Models must count exactly 6 intersection points. Each image contains 1-6 intersections.
About

IBench was created by Aditya Singh with the help of OpenAI's GPT-5.1 Codex and Anthropic's Claude Opus 4.5 for coding help.

All models tested via OpenRouter. Pricing estimates based on token usage at time of testing.

Methodology

Each model receives 100 synthetic images containing randomly placed line segments. The task: count the exact number of intersection points (ranging from 1 to 6 per image). Models are queried via the OpenRouter API with identical prompts. Accuracy measures exact match rate; MAE (Mean Absolute Error) shows average prediction deviation.
